Статья для дисциплины «Научное письмо», ПЗ-3 от 06.11.2026.

**Автор:** Арепьев Егор Сергеевич, НИТУ «МИСИС», БПМ-23-ПО-2.

Исследуются три стратегии RL-обучения G1 с кистью Inspire: общая политика полной задачи, отдельные Approach/Grasp/Lift и единая политика с последовательной сменой конечной цели. Приведены постановка задачи, обзор работ, методы и предварительные результаты в одной фиксированной симуляционной сцене.

## PDF и сборка

1. Открыть [GitHub Actions](https://github.com/LuckyP0tat0/g1-grasp-rl-paper/actions/workflows/build.yml).
2. Выбрать последний успешный запуск для нужного коммита.
3. В разделе **Artifacts** скачать **article.pdf**. `example.pdf` — исходный демонстрационный пример преподавателя, не наша статья.

PDF собирается автоматически при push и pull request; доступен также ручной запуск **Run workflow**. Используются Windows и Tectonic 0.17.0 с Times New Roman / Courier New. Обучение робота при сборке не запускается; доступ к приватному репозиторию и серверу не нужен.

Локальная сборка при установленном Tectonic:

```bash
python tools/check_article.py
mkdir -p build
tectonic -o build article.tex
```

Или XeLaTeX: дважды выполнить `xelatex article.tex`. Для Overleaf загрузить `article.tex`, `misisarticle.cls` и папку `figures/`, выбрать XeLaTeX. Класс оформления сохранён из [шаблона преподавателя](https://github.com/sadekovlar/misis-article-latex); файл `LICENSE` сохранён вместе с ним.

## Границы результатов

Срез данных проверен **6 ноября 2026 года**. Новый единый Approach получил 100/100 в двух оценках после 9,6 млн переходов; это не успешность полного захвата и подъёма. Последние включённые оценки следующего этапа Grasp — 0/100 в обеих проверках после 300 обновлений этапа. Разные серии используют разные старты и критерии; таблица не является рейтингом методов на общем тесте.

В репозитории находятся текст и агрегированные материалы статьи. Исходники рабочей среды RoboBenchMart, веса, полные журналы, настройки доступа и ассеты симулятора не входят в публикацию. Для полного воспроизведения экспериментов нужен отдельный согласованный пакет исследовательского проекта.
